# 4. リボン・キー操作・文字列

画面の文字（ボタンの名前、キーヒント、ツールチップ、メッセージ）と、リボンの構造は、日本語の言語リソース `ja/maillang.dll.mui` に入っています。

## 文字列・メニュー・ダイアログ

`tools/inventory/res.py` は、REA のリソース一覧（`inspect-pe-resources` の JSON）をもとに、MUI から次のものを取り出します。

- **文字列表**（RT_STRING）: 16 個ずつのまとまりを番号に直して `strings.tsv` にします。日本語版には 4,265 件ありました。
- **メニュー**（RT_MENU）: ふつうの形式と拡張形式の両方を読み、字下げした木にします。35 個。
- **ダイアログ**（RT_DIALOG）: 部品の種類・位置・大きさ・文字を並べます。188 個。オプション画面のタブの配置は、ここから写しました。

どれも Windows の公開された形式なので、難しくはありません。取り出すときは、REA の一覧にある SHA-256 で切り出した中身を照合しています。

## リボン（UIFILE）

リボンは Windows Ribbon Framework で作られていました。コンパイル済みのリボン定義が、MUI の `UIFILE` という種類に 8 つ入っています（メイン ウィンドウ、メッセージを開いた窓、作成の窓、予定の窓など）。先頭は `SCBin` です。

この形式は公開されていないので、バイト列の並びから読み方を割り出しました（`tools/inventory/bmllib.py`、`bml2.py`）。

- 先頭に**コマンド表**があります（245 件で、8 つとも同じ）。1 件は「コマンド番号（u32）、項目数（u8）、{種類（u8）、文字列の番号（u32）} の並び」です。種類は 1 がラベル、2 がラベルの説明、7 がキーヒント、8 がツールチップの題、9 がツールチップの説明です。[観察]
- 続いて**要素の木**です。1 つの要素は `16 種類(u16) 10 長さ(u16) 属性の数(u8)` と属性の並びです。属性の形は 4 種類ありました。キー・型・値の組、子の一覧、別の場所の塊を指すもの、値の並び（大きさの定義）です。[観察]
- 要素の種類の名前は推定です。並びと中身から、リボン、タブ、グループ、ボタン、ドロップダウン、分割ボタン、ギャラリー、クイック アクセス ツール バーなどを当てました。[推定]
- 属性の 1 つは「どの機能を表示しているときに出すか」のビットでした。メール（2）、ニュース（4）、フィード（8）、カレンダー（16）、アドレス帳（32）です。左下のナビで機能を切り替えると「ホーム」タブが入れ替わる仕組みは、これで説明できます。[推定]

コマンド番号は 10400〜13700 の範囲で、画像の番号と結びついています。

- 小さい画像（16px と 24px）は、コマンド番号と同じ番号の画像です。[観察]
- 大きい画像（32px と 48px）は、`msmail.dll` の `FUN_10038ff0` にある「コマンド番号 → 画像番号」の分岐（113 件）で決まります。[観察]

`tools/inventory/ribbons.py` はリボンの木とコマンド表をテキストに書き出します。`gen.py` は、それを確認用の表（項目・種類・番号・キーヒント・画像・表示モード）にします。

## キー操作（アクセラレーター表）

ショートカット キーは、MUI の RT_ACCELERATOR に 9 つの表で入っていました。メイン ウィンドウ全体、メッセージ一覧、メッセージを開いた窓、作成の窓、カレンダー、アドレス帳の表です。

1 件は 8 バイトで、`フラグ(u16) キー(u16) コマンド番号(u16) 詰め物(u16)` です。フラグは 1 が仮想キー、4 が Shift、8 が Ctrl、0x10 が Alt です（Windows の `ACCEL` 構造体と同じ）。[観察]

この表から、たとえば次のことがわかります。

- Ctrl+Q は「未開封 / 開封」の切り替えです。
- Ctrl+F は「転送」で、検索ではありません。
- 同じ Ctrl+Enter でも、メッセージ一覧では「開封済みにする」、作成の窓では「送信」です。表が窓ごとに分かれているためです。

作り直したアプリのキー操作は、この表に合わせました。

## 作り直しでの使い方

- リボンは本物と同じ並び、同じキーヒント、同じツールチップにしました。
- 作り直したアプリで実現できない機能（カレンダーの予定、アドレス帳、ニュースグループなど）も消さずに、**灰色（無効）にして同じ場所に置きました**。使う人から見て、ボタンの位置が変わらないことを優先しています。
